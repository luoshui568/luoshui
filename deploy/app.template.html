📖 使用说明
1. 打开工作台需先登录管理员账号，账号与密码保存在云端数据库（表 wb_admins，bcrypt 哈希），由服务端校验；勾选「记住这台设备」可 7 天免登录
2. 所有删除操作都需输入管理员密码，请求会带着密码提交到数据库函数校验，通过后才真正删除；浏览器已无权直接删表
3. 密码只存哈希、前端读不到；忘记密码需要用另一个管理员账号登录后在「数据与设置」中重置
4. 点任务左侧方块切换状态：待办 → 进行中 → 已完成 → 跳过；悬浮任务可编辑 / 改期 / 删除
5. 课表按周折叠，点周标题展开；所有改动先写本机缓存，云端可用时自动同步
6. 「工作计划」按今天 / 本周 / 本月 / 本季度 / 本年 / 五年 / 十年 / 二十年八档维度管理，可切「全景看板 / 按周期浏览 / 时间轴」三种视图
7. 「申请清单」覆盖境内主体、金融牌照、矿权、境外投资（ODI）、税务外汇、进出口、知产、人才八类
8. 想退出登录：本页右上角「🚪 退出登录」，或「管理员与安全」卡片内的同名按钮
9. 数据看板每 30 秒自动刷新一次统计
