📖 使用说明
1. 登录页分超级管理员与普通管理员两种角色：没有账号的成员可在登录页点「📝 注册普通管理员」自助申请，必须由超级管理员在「数据与设置 → 管理员与安全」中批准后才能登录（未批准前登录会提示等待批准）
2. 普通管理员登录后直接进入「投资标的」，可维护行情、标的等业务数据；新增 / 停用 / 删除账号与注册审批只有超级管理员能做，服务端函数强制校验角色
3. 账号与密码保存在云端数据库（表 wb_admins，bcrypt 哈希），由服务端校验；勾选「记住这台设备」可 7 天免登录
4. 任何会改动数据的操作都要输入管理员密码（新增 / 编辑 / 修改 / 保存 / 同步 / 导入 / 删除），请求带着密码提交到数据库函数校验，通过后才真正执行；「保存 / 修改」可勾 15 分钟内免重复输入，删除、审批与覆盖导入每次都需输入；浏览器已无权直接改表
5. 密码只存哈希、前端读不到；忘记密码需要用另一个管理员账号登录后在「数据与设置」中重置
6. 点任务左侧方块切换状态：待办 → 进行中 → 已完成 → 跳过；悬浮任务可编辑 / 改期 / 删除
7. 课表按周折叠，点周标题展开；所有改动先写本机缓存，云端可用时自动同步
8. 「工作计划」按今天 / 本周 / 本月 / 本季度 / 本年 / 五年 / 十年 / 二十年八档维度管理，可切「全景看板 / 按周期浏览 / 时间轴」三种视图
9. 「申请清单」覆盖境内主体、金融牌照、矿权、境外投资（ODI）、税务外汇、进出口、知产、人才八类
10. 想退出登录：本页右上角「🚪 退出登录」，或「管理员与安全」卡片内的同名按钮
11. 数据看板每 30 秒自动刷新一次统计
12. 「📚 研究报告」是独立页面（侧栏点进去，不占工作台的体量）：列出云端全部研报，点卡片打开完整研报；超级管理员与团队成员都能看，也仍可从「投资标的」列表点 📄 图标直接进
📖 使用说明（团队成员）
1. 你的菜单有三项：投资标的（维护股票池与行情）、研究报告（研报库，独立页面）和数据与设置（本页）
2. 修改自己的密码：下方「🔐 管理员与安全」卡片里点「🔑 修改我的密码」
3. 退出登录：本页右上角「🚪 退出登录」，或「管理员与安全」卡片内的同名按钮
4. 「☁️ 云端连接」可以查看连通状态；数据写入失败时这里会给出原因，点「↻ 立即同步」可重试
5. 超级管理员的私人工作区（总览 / 工作计划 / 365 天课表 / 申请与资质 / 标的与人脉 / 复盘日志）以及账号审批不对外开放，不会出现在你的菜单里
6. 任何会改动数据的操作都要输入你自己的管理员密码，由数据库函数校验，前端绕不过去
7. 研究报告：侧栏点「📚 研究报告」进研报库（独立页面），列出全部研报，点卡片打开完整研报；也可以直接在「投资标的」列表里点标的的 📄 图标
