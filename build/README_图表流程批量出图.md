# 时间轴 / 股权树批量出图 —— 快速使用手册

> 面向「以后再给 XX 公司做一条发展历程时间轴 + 一张股权结构树」的场景。
> 用 `build/chartflow.py`，一份数据 → 一段 HTML / 一张 SVG，不需要碰坐标。
>
> 与 `README_地图批量出图.md` 是一对：**地图**解决 ECharts 那 28 张图里的地理题，
> **本手册**解决 31 模块里唯二**不是 ECharts** 的两个视觉件。

---

## 一、它解决什么问题

31 个模块里，28 张图的出图链路是 `data-chart` 槽位 + 库表 `wb_report_charts`。
但这两件一直是**手工艺品**，换公司必须整段重写：

| 视觉件 | 原来 | 现在 |
|---|---|---|
| m2 公司发展历程 | 7 个 `.h-node` 写死在模块 HTML 里，7 节点、年份、正文全是字面量 | `TimelineKit.html(nodes, …)` |
| m3 股权结构树 | 内联 SVG，22 rect / 125 组绝对坐标，子公司 x 是手算等差 117.14 | `OrgTreeKit.svg(chain, subject, children)` |

## 二、最小用法

```python
import sys; sys.path.insert(0, r"<repo>/build")
from chartflow import TimelineKit, OrgTreeKit

# ---------- 时间轴 ----------
html = TimelineKit().build(              # build = selfcheck + html
    [('1999', '<b>宝钛集团</b>联合西北有色金属研究院设立宝钛股份'),
     ('2002', '4月12日<b>上交所上市</b>，中国钛工业第一股'),
     ('2026', '发行<b>35亿可转债</b>，三大项目')],
    en='COMPANY HISTORY',                # 可省，默认就是它
    title='公司发展历程',                 # 可省
    sub='二十余载 · 从代号902到中国钛工业第一股',
    foot='1999 — 2026 · 钛业报国 · 迈向航空航天新周期')

# ---------- 股权树 ----------
svg = OrgTreeKit().build(                # build = selfcheck + svg
    [('陕西省人民政府', '—'),              # 顶层实控人无上游，写 '—'
     ('陕西有色金属集团', '100%'),         # ← 省政府持有它 100%
     ('宝钛集团有限公司', '93.36%')],      # ← 陕西有色持有它 93.36%
    '宝鸡钛业股份有限公司（600456.SH）',
    [('宝钛华神钛业有限公司', '66.67%'),
     ('宝钛精密锻造有限公司', '40%'),
     …],
    subject_pct='49.40%')                # ← 宝钛集团持有上市公司 49.40%
```

`html` 直接塞进 m2 模块的 HTML；`svg` 外面套一层 `<div class="sh3-tree">` 塞进 m3。

## 三、三个比例语义（**最容易搞混，务必看清**）

股权链上会出现 3 个不同含义的百分比，混了就会把标签挂错边：

| 值 | 含义 | 挂在哪 |
|---|---|---|
| `chain[0].pct` | 顶层实控人，**没有上游** → 写 `'—'` | 不画 |
| `chain[i].pct` (i≥1) | **上一节点持有 `chain[i]` 的比例**（下游节点的**流入**比例） | `chain[i]` 的**入边** |
| `subject_pct` | 链末节点持有**上市公司主体**的比例 | 链末 → 上市公司的竖边 |

600456 实测：

```
陕西省人民政府  ──100%──▶  陕西有色金属集团  ──93.36%──▶  宝钛集团有限公司
                                                                    │
                                                                 49.40%
                                                                    ▼
                                                    宝鸡钛业股份有限公司（600456.SH）
```

- `chain[-1].pct` = **93.36%** = 宝钛集团**被**陕西有色持有 93.36%
- `subject_pct` = **49.40%** = 宝钛集团**持有**宝鸡钛业 49.40%

> ⚠️ 这两个数**不是一回事**。少传 `subject_pct` 时，工具会退回用 `chain[-1].pct`，
> 于是竖边上会错打 93.36%。`selfcheck()` 无法替你判断业务真值，只能保证
> 「传了的都被画出来」—— 所以 `subject_pct` 请**显式传**。

## 四、喂进去的数据长什么样

批量管线里，这两个视觉件的入参就是 `seed/data_v31_<code>.json` 里的两块：

```json
"timeline": {
  "en": "COMPANY HISTORY",
  "title": "公司发展历程",
  "sub": "二十余载 · 从代号902到中国钛工业第一股",
  "foot": "1999 — 2026 · 钛业报国 · 迈向航空航天新周期",
  "nodes": [["1999", "…"], ["2002", "…"], ["2026", "…"]]
},
"equity_tree": {
  "chain":  [["陕西省人民政府", "—"], ["陕西有色金属集团", "100%"], ["宝钛集团有限公司", "93.36%"]],
  "subject": "宝鸡钛业股份有限公司（600456.SH）",
  "subject_pct": "49.40%",
  "children": [["宝钛华神钛业有限公司", "66.67%"], ["宝钛精密锻造有限公司", "40%"]],
  "cap": ""
}
```

换公司只改这两个块，`report_build_v31.py` 的 `m2()` / `m3()` 会自动出视觉件。
**两块缺任一块** → 该模块回落到普通表格（不会报错，也不会编造数据）。

`nodes[i][1]` 里可以带 `<b>` 等行内标签（原设计就是富文本），但**不要带 `<div>`/`<style>`**
—— `sanitizeHtml` 会剥掉 `<style>`，模块级 CSS 只能写进 `build/report_theme.css`。

## 五、自适应规则（节点/子公司数量变了会怎样）

### 时间轴

| 量 | 7 节点（基准） | 其他节点数 n |
|---|---|---|
| 轨道高 | `345px`（与 600456 逐像素相同） | `max(260, min(560, round(345 * (7/n) ** 0.55)))` |
| 卡片宽 | `146px` | `n ≤ 7` 时 146；否则 `max(118, int(146 * (7/n) ** 0.35))` |

序号限制：**3 ≤ n ≤ 12**。少于 3 不像时间轴，多于 12 卡片糊成一片。

> ⚠️ 高度与宽度都是写成**行内 style** 的（`style="height:…px;"`），不是改 CSS。
> 因为 `sanitizeHtml` 会剥掉模块内的 `<style>`，而 `.h-track{height:345px}` 是全局硬编码。
> 行内样式是唯一能按实例覆盖的通道。

### 股权树

画布固定 `1000 × 550`（`viewBox`），几何全部由 `layout()` 单一函数推导：

- 叶子槽宽 `slot = (1000 - 2×40) / n`；卡片宽 `lw = min(120, max(60, slot - 15))`
  ⇒ n=8 时 slot=115、lw=100，与 600456 现值**逐像素相同**
- 叶子 x：`40 + step×i`，`step = (1000 - 80 - lw) / (n-1)` ⇒ n=8 时步长 117.14
- 纵向节奏：`链节点 14 / 90 / …` → 主体条 `186` → 叶子 `308`
- 画布高度会按内容自动撑高（`max(550, leaf_y + 212 + 30)`）

名称竖排字号自适应：≤10 字用 14px / 行距 15.2，≤13 字用 12.5 / 14.0，更长用 11.0 / 12.6。

**层级数（`chain` 长度）**：

- `len(chain) == 1`：无实控人（直接就是上市公司），画一个居中 460 宽条
- `len(chain) >= 2`：前 `n-1` 个竖排在左（x=125），**最后一个横排在右**（与倒数第二个同行）

## 六、做完必跑 `selfcheck()`

`build()` 已经内置（先自检再渲染）；想单独体检就显式调：

```python
TimelineKit().selfcheck(nodes)          # 返回 True，不通过直接 raise
OrgTreeKit().selfcheck(chain, subject, children, subject_pct)
```

写进去的断言，每条都对应历史上踩过的一个坑：

| 断言 | 挡住的坑 |
|---|---|
| 节点数 ∈ [3, 12]；每节点有年份+正文 | 数据缺列/空数组 |
| `h-node` / `h-dot` / `h-card` 三者数量都 == n | 结构少包一层 div ⇒ `:nth-child(odd/even)` 交错失效 |
| 每个 `h-node` 内恰好 1 个 dot + 1 个 card | 交错方向错乱 |
| 行内 `height` == `track_height(n)`、行内 `width` 存在 | 高度没跟着节点数走 ⇒ 挤爆 / 拉太空 |
| 叶子卡片不重叠、不越界（x 单调、间距 > 0） | 子公司数量变了 x 体系失效 |
| 叶子竖排 tspan 总高 ≤ 卡片高 − padding | 12 字长名溢出卡片 |
| `chain[1:]` 每个节点**必须有比例**（非 `—`/空） | **93.36% 整个丢失**那个 bug |
| rect 总数 == `n + 1 + 2×nk + has_subj + (n≥3)` | 少画了转弯边的徽标 / 少画主体条 |
| tspan 总数 == 叶子名总字数 | 逐字排布丢字 |
| SVG 里无 `None` / `nan` | 缺失字段被字符串化打进画布 |
| **两次渲染结果逐字节相同** | 改写脚本最常见的非幂等源 |

> `selfcheck()` 与 `html()`/`svg()` **是分开的**。渲染函数绝不调用自检 —— 否则
> 「渲染 → 自检 → 渲染」会 `RecursionError`。取证由 `selfcheck()` 单向调渲染完成。

## 八、已知边界

- **股权树无窄屏降级**。`.sh3-tree svg{width:100%;height:auto}` 靠 viewBox 等比缩放，
  1000×550 在手机上会把 8 家子公司的竖排字压到几乎不可读。
  时间轴有 `@media(max-width:860px)` 的纵向降级，树状图**没有**（待办）。
- **`chain[0].pct` 目前不画**。顶层实控人上面确实没东西，写 `—` 是正解；
  但如果遇到「两个实控人平级持股」这类结构，本工具表达不了，需另设计。
- **叶子固定 4 层节奏**（链 → 主体 → 子）。目前不支持「子公司下面再挂孙公司」。
- **比例只做展示，不做校验**。工具不会去核对 `93.36% × 49.40%` 之类的联动关系，
  数据对不对由取数侧负责（`[MISSING]` 而非编造）。
