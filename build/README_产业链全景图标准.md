## 2. 规格 JSON 字段

| 字段 | 说明 |
|---|---|
| `code` / `name` | 股票代码 / 名称（只用于自检打印） |
| `h` | 画布高（默认 376；宝钛用到 352）。**改了 h 一定要跑 `lint()`** |
| `lanes[]` | `{id,t,sub,x,w}` —— 泳道横幅。`id` 用 `up/mid/down`，节点靠它归属 |
| `nodes[]` | `{id,t,s,x,y,w,h,lane,b}` —— `t` 主标题（**≤7 字**）、`s` 副行（**≤9 字**，`FS_S=9.6`）、`b` 比例徽章文案（挂在框下方 9px，**≤11 字**） |
| `chips[]` | `{id,t,v,x?,y,w?,h?}` —— 右侧比例条。`t` 名称（**≤13 字**）、`v` 占比（`""` = 只画条不写值，如塑料/造纸） |
| `edges[]` | `{from,to,kind,dashed?}`；`kind` ∈ `h/v/t/e/fan`（见下） |
| `bars[]` | `[{id,head,rows:[{l,pct,v}]}]` —— 底部比例尺，`pct` 是 0–100 的数，`v` 是显示文案 |
| `note` | 读图 + 口径与来源（HTML，允许 `<b>`/`<br>`）。**不许编造**，每个数字都要能落到来源 |

### 边（edges.kind）

| kind | 走法 | 附参 |
|---|---|---|
| `h` | 起点右缘 → 终点左缘，直线箭头 | — |
| `v` | 起点下缘 → 终点上缘 | — |
| `t` | 起点右缘横出 → 中点 → 竖走 → 汇入终点左缘 | `xm`（竖走的 x，默认中点） |
| `e` | 起点下缘下走 → `ym` → 右行汇入终点左缘 | `ym`（横向走线的 y）、`x`（下走点，用来避开下方徽章） |
| `fan` | **分组括线**：起点右缘横出 → 竖括 → 每个下游条各一小横线 | `ids`（下游条 id 列表）、`dashed` |

## 3. 内容纪律（照抄模块 3 的规矩）

1. **不估算、不编造**。比例只有「行业报告口径 / 公司披露口径」两种，写进 `note` 里说清是哪一种。
   查不到就**不写**（`v:""` 或干脆不给 `b`），绝不用"约等于"凑数。
2. 徽章里的比例**不是**公司分行业收入结构 —— 这一句必须写在 `note` 里，否则读者会误读。
3. 节点主标题 / 副行 / 徽章 / 比例条名称都有长度上限（见上表）——
   超了会被 `lint()` 拦下，因为会溢出 104 宽的节点框或顶掉右侧占比。
4. `note` 至少 150 字，必须包含「读图」+「口径与来源」两节。

## 5. 探针 `build/probe_chain_m22.py` 量什么

`--w=820` 换视口；`--cloud` 从线上库拉数据；`--scale=2 --sh=1150` 出放大截图。
默认**清空云配置走 seed**（零请求、不碰生产表）。检查项：

* 骨架：泳道 3 / 节点 8 / 比例条 8 / 图例 4 / tooltip 齐全
* 节点框**内**文字溢出 = 0（徽章允许挂在框外，但必须横向居中、不与任何东西相撞）
* 比例条「名称↔占比」最小水平间距 ≥ 2px；相邻比例条纵向最小间隙 ≥ 1px
* 跨节点文字框相撞 = 0；节点不越出自己那段泳道；图元不越出 viewBox
* 比例尺：3 组、条宽 % 与数值文案自洽、行内文字不被裁
* 显示功能：`.iflow:hover .nd/.cp` 规则在位、`@media print` 有还原、≤860 有适配、窄屏可横滑且 svg 保持 740 最小宽

## 6. 已知坑（写代码前先看）

* **`.ifbars` / `.if-note` 是 `.iflow` 的兄弟节点**，不在 `.iflow` 里面 —— 探针/脚本用 `flow.querySelector` 会数到 0。
* **泳道横幅只用来定「横向归属」**：节点挂在横幅**下面**，所以"是否越段"只能比 x 范围，拿横幅 y 去卡节点一定误报。
* **徽章是故意挂在节点框下方的**（`BADGE_DY=9`），不是溢出；相撞由 `lint()` 与探针的跨组检测兜。
* **比例尺轨道要给足 84px**：给 62px 时 16% 这种小占比会缩成一个小圆点（实测截图），
  轨道 84px + 圆角 3px 才读得出"条"。
* **短条别用大圆角**：`border-radius:4px` 配 7px 高在 16% 处看着像圆形；改 3px + 8px 高。
* 中文宽度按 `_tw()` 估：汉字 1.0em、其余 0.55em —— 排版对不对靠它，别凭感觉。
* 编辑 SVG 文本时注意 `&`、`<` 要转义（`_esc()`）；`<title>` 里可以有中文与全角标点。

### 7.2 探针「总分」静默假绿（已修，务必知情）

`probe_chain_m22.py` 原用 `ok = True` + `def chk(...): global ok`，但 `main()` 里另有一个局部 `ok` —— 
判定结果丢在模块级，`main` 里的 `ok` 恒为 `True`，**「总分」永远是「全绿」**，属静默假绿。
且骨架数量写死 8，篇目规模不同时也会误报。现改为：

* `red = []` 收集失败项，`chk` 里 `if not cond: red.append(msg)`；
* 期望节点/徽章数从 `build/seed/chainstd/chain_<code>.json` **读真值**（缺规格才回落 8）；
* 末尾打印 `总分：全绿 / 有 N 项红 —— 先别上线`，`return 0 if not red else 2`。

> **教训**：判据用「列表收集」而不是「布尔累加」，且**期望值要从规格文件读**、不要写死 —— 否则「测试改完才发现它一直在骗你」。
