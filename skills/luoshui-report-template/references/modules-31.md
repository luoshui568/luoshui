## 关键约定

1. **第 24 槽标题带 `{ind}` 占位符** —— 由 `title_of()` 用 `industry_short` 填入，
   变成「钛行业介绍与市场规模」这种。**用短名**，不要用 `industry_name`
   （后者常带申万/证监会括号注释，塞进标题会很长）。
2. **第 28 槽是合并槽**：原「估值分析 + 估值敏感性 + 公司股价表现」三块合成一节
   （宝钛母本只有一节）。所以 `POS2RENDER[28]='m_val'`，且 `m_val` 允许唯一重复。
3. **第 9 槽用 `m12` 渲染器**（管理层与治理），**第 24 槽用 `m9`**（行业总览与市场空间）
   —— 位置与渲染器编号**不是一对一**，见下表。
4. **第 25 / 26 槽是本轮新增**，渲染器 `m_res` / `m_sdbalance`（数据块 `resource` / `sdbalance`）。

## 模块编号契约（重排必读）

- 库内模块 id = **`{code}_m{no}`**，`no` 是 **1..31 的位置号**（字符串）。
- 任何**重排/换位**都是"改主键"，必须**整位重写**：
  先全部改成**临时值**，再落到终值 —— 否则 `m9 ↔ m19` 会**撞主键**。
  参考 `build/move_mod_600456.py` 的「两段式改号」。
- `report_build_v31.py` 收尾会断言：
  - `nos == ['1'..'31']`（编号连续）
  - 模块 HTML 里 `data-chart="X"` 的集合 ⊆ 图表数据的 id 集合（图槽必须有图）
  - `report.kpis / toc / verdict_html / essence_html` 都不能空
